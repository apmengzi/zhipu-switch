# Privacy Policy · 隐私政策

**English**

zhipu-switch (the userscript and the browser-extension build in `edge-ext/`) is a local tool for managing the user's own chatglm.cn accounts.

- **What it stores:** the login tokens (chatglm_token / chatglm_refresh_token) and a per-account device identifier of the accounts **the user themselves logs into**, saved **only** in the browser's localStorage on the user's own machine. Nothing is uploaded to the developer or to any third party.
- **What it sends:** requests go **only** to chatglm.cn, using the user's own logged-in session, to read credit balance and claim the site's daily login bonus. No telemetry, no analytics, no remote code loading.
- **What it does not do:** no tracking, no profiling, no selling or sharing of data, no data collection of any kind beyond the local storage described above.
- **Deletion:** removing an account from the pool deletes its local record; clearing browser storage / uninstalling the extension erases everything.

Contact: https://github.com/apmengzi/zhipu-switch/issues

**简体中文**

zhipu-switch(用户脚本版与 `edge-ext/` 浏览器扩展版)是管理用户**本人** chatglm.cn 账号的本地工具。

- **存什么:** 用户自己登录的账号的登录凭据(chatglm_token / chatglm_refresh_token)与每号设备标识,**仅**保存在用户本机浏览器的 localStorage 中;不上传给开发者,也不上传给任何第三方。
- **发什么:** 所有请求**仅**发往 chatglm.cn 本站(使用用户自己的登录态),用于查询积分余额与领取站方每日登录赠分;无遥测、无统计、不加载任何远程代码。
- **不做什么:** 不追踪、不画像、不出售或共享任何数据;除上述本地存储外不收集任何数据。
- **如何删除:** 在账号池中移除某账号即删除其本地记录;清除浏览器数据或卸载扩展即可删除全部数据。

联系方式:https://github.com/apmengzi/zhipu-switch/issues

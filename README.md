# zhipu-switch · 智谱清言多账号积分助手（油猴插件）

> 一个为 **智谱清言 2026 双节活动**（2026-09-25 ~ 10-07：每日登录自动赠 2000 分、连签翻倍、假期消耗 100% 返还）而做的浏览器用户脚本。
> 在 chatglm.cn 页面里直接管理多个账号的积分：余额悬浮窗、一键签到、一键切换账号、一键添加账号——**不用反复退出登录**。

## 这是什么

智谱清言的双节活动按"账号"发积分,而网页端一个浏览器同一时间只能登录一个账号,想给几个号都领分就得来回退出/登录/抓 token,非常麻烦。这个插件把整件事变成页面右下角一个小悬浮窗:

- **每日登录赠分自动兜底**:页面加载后自动幂等地领一次当日登录分(活动积分,页面通常已自发,插件保证不漏)
- **多账号池**:把各账号的登录 token 存进浏览器本地(localStorage),池内显示每个号的余额与签到结果
- **全部签到**:一键遍历池内所有账号调每日登录赠分接口(幂等,已领自动跳过)
- **一键切换账号**:点一下即写回该号的登录态并刷新——像切换器一样在账号间跳,无需退出登录
- **一键添加账号**:自动快照当前号 → 进入访客态(带引导提示)→ 你登录/注册新号 → 插件自动捕获新号 token 入池 → **自动切回原号**。全程无需手动导出
- **悬浮窗可收起**:收起后变成一个圆形小图标,点开展开
- **导出池文件**:把整个账号池下载为 JSON,可供本地工具(如自建 relay)导入

四种方式任选其一(前两种需要用户脚本管理器;后两种不需要):

**方式一 · 一键安装(推荐,需 Tampermonkey / 脚本猫)**

安装好 Tampermonkey 或 ScriptCat 后,直接点这个链接,管理器会自动弹出安装确认页:

**方式二 · GreasyFork 安装**

👉 [GreasyFork 页面](https://greasyfork.org/zh-CN/scripts/597547) —— 打开点「安装此脚本」即可;本站与 GitHub 仓库每日自动同步。

**方式三 · 脚本猫商店安装**

👉 [ScriptCat 商店页面](https://scriptcat.org/zh-CN/script-show-page/8138) —— 打开点「安装」即可(用 ScriptCat 扩展)。

**方式四 · 浏览器开发者模式加载(不需要任何脚本管理器)**

本仓库 `edge-ext/` 目录提供打包好的 MV3 浏览器扩展(功能与脚本版相同):

1. 下载本仓库 `edge-ext` 目录(含 `manifest.json`、`content.js`、`icons/`)
2. Edge 地址栏输入 `edge://extensions` → 打开右上角「开发人员模式」→「加载解压缩的扩展」→ 选择 `edge-ext` 目录(Chrome 用 `chrome://extensions` 同理)
3. 打开 chatglm.cn 即生效

**方式五 · 手动粘贴**

打开脚本管理器面板 → 添加新脚本 → 全选粘贴 [`zhipu-switch.user.js`](./zhipu-switch.user.js) 内容 → 保存(Ctrl+S)。

安装后打开 [chatglm.cn](https://chatglm.cn/) 并登录,右下角出现悬浮窗即生效。

## 使用多账号

- 「添加账号」→ 页面进入访客态(有 toast 引导)→ 点页面右上角【登录】登录另一个账号(或注册新号)→ 插件自动把新号入池并切回你之前的号
- 池里点某号的「切」即可切换登录;点「×」仅删除本地记录,不影响账号本身

## 工作原理(简述)

- 登录态 = cookie 里的 `chatglm_token`(24h)+ `chatglm_refresh_token`(约 50 天),页面 JS 自身用 js-cookie 读写(非 HttpOnly),插件据此实现"写 cookie 即切换"
- 签名头 `X-Sign` 的算法与页面 bundle 一致(md5,模块 55569 原样内嵌)
- 访客账号通过 JWT payload 的 `is_guest` 字段精确识别,不会被误当成新登录
- 设备指纹(localStorage `chatglm-deid`)每个池内账号独立一份,切换/添加时随号写入

## 安全与隐私

- ⚠️ 账号池(token)以**明文**存于浏览器 localStorage、导出文件亦为明文——**请勿在共用电脑使用,勿把导出文件发给别人**
- 插件仅与 chatglm.cn 本站通信(签到、查余额、user/info),不接任何第三方服务
- 代码无混淆、无远程加载,可自行审计
